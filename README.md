# 🎬 YouTube-Clone-FullStack

A full-stack YouTube clone built using the MERN stack with features like authentication, video upload, likes, comments, watch history, and watch later.

## 🚀 Tech Stack

- React.js
- Redux
- Node.js
- Express.js
- MongoDB
- JWT Authentication

---

## ✨ Features

- User Authentication
- Upload & Watch Videos
- Like / Dislike Videos
- Comment System
- Watch History
- Watch Later
- Responsive Design
